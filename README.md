# アプリ「コスパドーレ（Cospadore）」プライバシーポリシー

本アプリ「コスパドーレ（Cospadore）」における、ユーザー情報の取り扱いについて以下のとおり定めます。

---

### 1. 個人情報の収集について
本アプリは、ユーザーの氏名、メールアドレス、位置情報、端末識別子などの個人情報および利用データを一切収集・送信・蓄積いたしません。

### 2. 利用データの保存について
アプリ内で設定された情報は、すべてお使いの端末内（ローカル環境）にのみ安全に保存されます。外部サーバー等へ送信されることはありません。

### 3. アクセス解析・広告配信について
本アプリでは、第三者によるアクセス解析ツールや広告配信サービスは使用しておりません。
